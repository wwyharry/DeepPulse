## 战法文件格式

每个战法文件采用 Markdown 格式，包含以下部分：

```markdown
# 战法名称

## 适用场景
描述战法适用的市场环境和股票特征。

## 核心条件
- 条件1：...
- 条件2：...

## 买入信号
- **激进买入**：...
- **稳健买入**：...

## 卖出信号
- **止盈**：...
- **止损**：...

## 关键指标
- 指标1：...
- 指标2：...

## 典型案例
描述典型案例和操作要点。

## 风险提示
- 风险1：...
- 风险2：...
```

## 添加自定义战法

1. 在本目录下创建新的 `.md` 文件
2. 按照上述格式编写战法内容
3. 系统会自动加载新战法

## 战法检索

系统支持以下方式检索战法：
- 关键词匹配（技术指标、形态特征）
- 标签匹配（战法分类）
- 内容全文搜索

## 使用方式

### 通过 Agent 对话
```
用户: 帮我找适合放量突破的战法
Agent: [自动调用 search_strategy("放量突破")]
```

### 通过 Web 界面
访问 http://localhost:8000 → 战法页面

### 通过 API
```bash
# 列出所有战法
curl http://localhost:8000/api/strategy/list

# 搜索战法
curl -X POST http://localhost:8000/api/strategy/search \
  -H "Content-Type: application/json" \
  -d '{"query": "放量突破"}'

# 获取战法详情
curl http://localhost:8000/api/strategy/{strategy_id}
```
